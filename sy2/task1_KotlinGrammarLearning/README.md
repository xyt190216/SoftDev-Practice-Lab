## 一、 实验内容

根据课程要求，本次实验主要通过在线交互式平台完成 Kotlin 语法的学习与练习：

1. **学习重点**：
   - 变量声明（`val` 与 `var`）及类型推断。
   - 空安全基础（可空类型 `?`、安全调用 `?.`、Elvis 运算符 `?:`）。
   - 控制流（`if` 表达式、`when` 分支、区间 `ranges`）。
   - 函数定义、Lambda 表达式与高阶函数。
   - 集合操作（`List`、`Map` 的过滤与映射）。
   - 类与数据类（`data class`）的建模方式。
